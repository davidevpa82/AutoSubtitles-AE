# Auto Subtitles — панель субтитров для After Effects 2024

Автоматически раскладывает субтитры из `.srt` / `.vtt` по таймлайну AE: каждая фраза становится текстовым слоем с точным временем показа. Поддерживает **два языка одновременно** — русская дорожка снизу крупно, английская над ней мельче.

Совместимо: **After Effects 2024 (24.x)** и новее (минимум 17.x / AE 2020).

---

## Установка

Файл панели уже скопирован по пути:

```
C:\Users\<пользователь>\AppData\Roaming\Adobe\After Effects\24.6\Scripts\ScriptUI Panels\AutoSubtitles.jsx
```

Дальше:

1. Перезапустите After Effects.
2. Меню **Window (Окно)** → внизу списка → **AutoSubtitles.jsx** — панель закрепится где угодно в интерфейсе.

Если файл надо установить вручную (обновить версию):

```powershell
Copy-Item "C:\Users\oNePlay\OneDrive\Desktop\opencode\comp\AutoSubtitles-AE\AutoSubtitles.jsx" `
  "$env:APPDATA\Adobe\After Effects\24.6\Scripts\ScriptUI Panels\" -Force
```

Альтернативный запуск без панели: **File > Scripts > Run Script File...** → выбрать `AutoSubtitles.jsx` (откроется плавающее окно).

## Если AE "крякнутая" сборка

Панель — обычный ExtendScript-скрипт: она **не использует Creative Cloud, авторизацию и сеть**, поэтому тип "сборки" ей безразличен. Что реально проверить:

1. **Редактирование (Edit) > Настройки (Preferences) > Сценарии и Expressions** — включите галочку
   **«Разрешить сценариям записывать файлы и доступ к сети» (Allow Scripts to Write Files and Access Network)**.
   Сама панель только *читает* файл субтитров, но многие взломанные сборки имеют вырезанные/заблокированные системные диалоги — с этой галкой не будет отказов.
2. Если после установки пункт не появился в меню Window — AE не видит папку пользовательских скриптов. Тогда скопируйте файл прямо в папку программы (нужны права администратора):
   ```
   C:\Program Files\Adobe\Adobe After Effects 2024\Support Files\Scripts\ScriptUI Panels\
   ```

## Быстрый старт: русские + английские субтитры

1. Откройте (или создайте) композицию с роликом.
2. В панели:
   - **Файл 1** — русский `.srt` (это нижняя, крупная дорожка).
   - Включите галку **«Второй язык сверху»**.
   - **Файл 2** — английский `.srt`.
   - Цвет/размер/отступ второй дорожки настраивается строкой «Цвет 2 / Размер 2 / Отступ 2 / Сдвиг 2».
3. Нажмите **«Создать субтитры»**.

Результат: текстовые слои `RU 001...`, `EN 001...` с точными in/out точками, плавным затуханием (если включено) и отступом от низа кадра. Всё создаётся одной группой Undo: `Ctrl+Z` откатит весь импорт целиком.

Если для фильма нужен только один язык — просто не включайте галку «Второй язык».

## Живая строка «что делать дальше» (v1.17)

Удалена в **v1.19.11** (по запросу пользователя): подсказки «Шаг 1/2/3» и дублирующий прогресс Whisper убраны — прогресс виден в собственной строке статуса Whisper («Whisper: N%» + полоса прогресса рядом с кнопкой «Стоп»), а порядок действий подсказывают сами кнопки. Панель стала на строку компактнее.

## Словарь-подсказка Whisper (v1.17+)

Поле **«Словарь:»** во вкладке «Видео» — список имён и жаргона через запятую («Алексей Карпушов, TikTok, капиба»). Передаётся в Whisper как `--initial_prompt`: он будет писать эти слова правильно, а не «Шершер», «ток-ток». Хватает 5–15 слов.

Кириллица безопасна: панель кладёт словарь в файл `%TEMP%\AutoSubWhisper_prompt.txt` (UTF-8) и передаёт путь, а не текст в командной строке.

## Караоке-подсветка слов (v1.18+) — как в TikTok

Слова реплики подсвечиваются цветом **по ходу речи** — с настоящими таймингами слов от Whisper (`--word_timestamps`), а не «поровну на всех»:

1. Во вкладке «Стиль» включена галочка **«Караоке: подсветка слов по речи»** (вкл. по умолчанию).
2. Запустите **«Whisper → SRT»** — теперь он вернёт JSON с таймингами каждого слова и положит рядом с SRT файл `ролик.<lang>.kar.json`.
3. **«Загрузить SRT»** → **«Создать субтитры»**.

На каждую реплику создаётся **2 слоя**: обычный `RU 001: ...` (весь текст) и сверху `RU 001 ♪` — дубликат жёлтым цветом, который при помощи ключевых кадров Source Text рисует *сказанную часть* фразы шаг за шагом. Не сказанное остаётся базовым цветом — классическая караоке-подсветка.

Подробности:

- Ничего не анимируется выражениями — только ключевые кадры (безопасно для крякнутых сборок).
- Если `kar.json` рядом с SRT нет (Whisper запускался до этой версии или без галочки) — реплики создадутся обычными, панель напишет об этом в отчёте.
- Пересоздание с «Стереть прежние субтитры» чистит и `♪`-слои.
- Двойной клик по реплике в редакторе → выделяются **все её слои сразу** (база + `♪` + фон-полоса) — правишь стиль одного клика, не листая сотни слоёв (v1.19.2: по метке реплики в комментарии слоя; работает и в режиме «по одному слову» — выделятся все слова реплики).
- Скорость Whisper с word_timestamps чуть ниже (~+10–20%) — плата за точные тайминги слов.


## Фон-полоса за текстом (v1.19) — читаемость на светлом видео

Галочка **«Фон: тёмная полоса за текстом»** во вкладке «Стиль» (выкл. по умолчанию) — простая «плашка уровня CapCut»: тёмный скруглённый полупрозрачный прямоугольник ЗА текстом каждой реплики. Это НЕ возврат плашек Premiere Pro 24 (удалены в v1.8): никаких выражений и `sourceRectAtTime` — только ключевые кадры, безопасно для любых сборок AE.

- Работает для **обеих дорожек** (RU и EN), обычных реплик, караоке-«♪» и режима «по одному слову».
- Полоса — shape-слой, **ребёнок текстового слоя**: Pop/Слайд ведут её автоматически, прозрачность повторяет затухание текста. Живёт ровно на длительность реплики.
- В «по одному слову» полоса **одна на всю реплику** — по ширине самого длинного слова, рисуется под всеми словами и не гаснет на середине реплики (доведено в v1.19.1).
- Размер оценивается по параметрам текста (шрифт/размер/строки) — подгон «Под размер компа» учитывается автоматически.
- Пересоздание с «Стереть прежние субтитры» чистит и полосы (слои «… bg»).
- Состояние галочки входит в **свои пресеты** («💾 Сохранить» во вкладке «Эффекты») и в автозапоминание настроек.


## Экспорт ASS с караоке (v1.19.5+) — подсветка слов для других программ

В редакторе субтитров кнопка **«ASS (караоке)»** сохраняет текущую дорожку в Advanced SubStation `.ass` РЯДОМ с SRT. Проект AE не трогается — это просто файл, который можно подложить друзьям-монтажёрам или проиграть в плеере, где встроят титры.

- **Караоке-подсветка `{\\k}`** — по тем же таймингам Whisper, что и в панели: жёлтый «съедает» белый текст слово за словом (Primary = жёлтый акцент, Secondary = цвет дорожки). Нужен файл `<имя>.kar.json` рядом с SRT — его создаёт **Whisper с галочкой «Караоке»** (тайминги есть только у Файла 1; у перевода EN их нет — его реплики экспортируются обычными строками).
- **Стиль = панельный**: шрифт, размер (1/2 в редакторе), цвет дорожки, обводка (или фон-подложка — тогда BorderStyle=3, тёмный полупрозрачный box, как полоса в AE), отступ снизу, `\fad` из «Аним., с».
- Формат `v4.00+`, PlayRes берётся из полей нова компа (по умолчанию 1920×1080), время `H:MM:SS.CC`.
- Открывается в VLC, Media Player Classic, DaVinci Resolve, mpv, а также Premiere (плагины) и сайты с автотитрами.
- Несовпавшие с kar.json реплики (например, после правки текста) экспортируются без подсветки — файл в любом случае корректный.

**Как пользоваться:** открыть редактор («Редактор субтитров»), выбрать дорожку «Файл 1 — RU», нажать **ASS (караоке)** — рядом с SRT появится `<имя>.ass`.


## Полный цикл: субтитры прямо из видео (в панели)

Блок **«Из видео (Whisper)»** в панели делает всё по цепочке:

1. **Выбрать видео** — укажите `mp4/mov/avi` файл.
2. **Комп с видео** — создаёт композицию точно по размеру/кадровой частоте ролика и кладёт его на таймлайн.
3. Язык речи и модель (`tiny/base/small/medium`; по умолчанию `small`) + галка «Перевести на 2-й яз.» — тогда Whisper-дорожка ещё и переводится (ru↔en).
4. **Whisper → SRT** — запускает консоль (свёрнутую): расшифровывает речь и сохраняет рядом с видео `ролик.ru.srt` / `ролик.en.srt`. Первый запуск скачивает модель из интернета.
5. Прямо в панели виден **живой прогресс**: процент, elapsed и **ETA** — «осталось ≈ 7 мин · к 14:38». Если Whisper молчит, ETA считается по длительности видео и модели.
6. **Загрузить SRT** — подтаскивает готовые файлы в дорожки 1/2 панели.
7. **«Создать субтитры»** — субтитры на таймлайне поверх вашего ролика.

Эквивалент вручную: `powershell -ExecutionPolicy Bypass -File transcribe-video.ps1 -Video "ролик.mp4" -Lang ru -Model small -SecondLang en`

### Скорость Whisper

Whisper работает НЕ быстрее реального времени. Ориентир на 1 час ролика:

| Модель | CPU (примерно) | RTX 4060 Ti (CUDA) | Точность |
|--------|----------------|--------------------|----------|
| tiny   | ~7–10 мин      | < 1 мин            | посередине, ошибки в имЁнах |
| base   | ~20 мин        | ~1–2 мин           | неплохо |
| small  | ~40–60 мин     | ~2–4 мин           | хорошо (по умолчанию) |
| medium | ~2 ч           | ~4–8 мин           | максимальное качество |

Whisper сам выбирает CUDA, если PyTorch установлен в GPU-сборке — отдельного
переключателя не нужно. На этой машине уже стоит GPU-сборка (torch cu130,
RTX 4060 Ti 8 ГБ): 1.4-минутный ролик расшифровывается за ~10–15 секунд.

Для длинных записей без GPU выбирайте `tiny` или `base`.

## Как получить файл .srt

### Вариант 1. Whisper — расшивка голоса (бесплатно, офлайн, качество высокое)

```powershell
# один раз: ffmpeg + whisper
winget install --id Gyan.FFmpeg -e
pip install openai-whisper

# русские субтитры
whisper C:\video\rolik.mp4 --language Russian --model small --output_format srt --output_dir C:\video

# английские субтитры (режим распознавания принудительно EN)
whisper C:\video\rolik.mp4 --language English --model small --output_format srt --output_dir C:\video
```

`small` — быстро и прилично; `medium` — точнее для русского, но медленно.

### Вариант 2. Онлайн-сервисы

Наиболее известные: Sonix, HappyScribe, Amberscript, Subtitles Editor — большинство даёт скачать готовый `.srt`.

## Перевод: translate-srt.ps1

Если есть субтитры только на одном языке, второй генерируется переводчиком, тайминги сохраняются:

```powershell
# EN → RU
powershell -ExecutionPolicy Bypass -File "C:\Users\oNePlay\OneDrive\Desktop\opencode\comp\AutoSubtitles-AE\translate-srt.ps1" `
  -InputFile "C:\video\rolik.en.srt" -Target ru

# RU → EN
powershell -ExecutionPolicy Bypass -File "...translate-srt.ps1" -InputFile "C:\video\rolik.ru.srt" -Target en
```

Параметры:

| Параметр | Что делает |
|---|---|
| `-InputFile` | исходный .srt |
| `-Target` | язык перевода: `ru`, `en`, `uk`, `de`, `fr`, `es`, `it`, `pl`, `kk`, `zh`, `ja`, `ko` |
| `-OutputFile` | куда сохранить (по умолчанию `имя.<Target>.srt`) |
| `-DelayMs` | пауза между запросами (защита от blockировки Google) |

Требуется интернет; используется публичный бесплатный эндпоинт translate.googleapis.com (не официальное API, может иногда не отвечать — для этого в скрипте есть повторы).

## Настройки панели

| Поле | Значение |
|---|---|
| Кодировка | `Авто` (синт: BOM / байты UTF-8 / cp1251), `UTF-8`, `windows-1251` |
| Куда | в **активную композицию** или в **новую** (W/H/FPS задаётся полями) |
| Шрифт / Размер 1 / Цвет 1 / Обводка | стиль нижней (основной) дорожки |
| Отступ 1 | высота нижнего края от низа кадра (px) |
| Перенос строк | авто-разбивка длинной фразы (по умолчанию 42 символа) |
| Затухание | плавное появление/исчезание, секунды (0 = без анимации) |
| Сдвиг 1 / Сдвиг 2 | смещение времени дорожек ±секунды (рассинхрон) |
| Маркеры | композиционные маркеры в начале каждой фразы |
| Удлинять комп. | если субтитры выходят за хронометраж — композиция удлиняется |

Слои называются `RU 001: ...`, `EN 001: ...` — легко найти и отредактировать.

## Вкладки и регулировка (v1.13+)

Панель разбита на **4 вкладки** (ничего не «листается» одним длинным простынём):

- **ВИДЕО → SRT** — видео, язык, модель Whisper, запуск/стоп, прогресс.
- **ДОРОЖКИ И ФАЙЛЫ** — файлы 1/2, второй язык, стиль дорожки EN, куда создавать, кнопка «Субтитры от выбранного слоя», ✎ Редактор субтитров.
- **СТИЛЬ ТЕКСТА** — пресеты-переключатели (CapCut/TikTok/YouTube/Минимал, сеткой 2×2), шрифт, размеры, цвета, анимация, караоке-режим, фон-полоса за текстом, тайминг (мин. показ / пауза / вплотную), быстрая регулировка сдвига RU.
- **ЭФФЕКТЫ И СВОИ ПРЕСЕТЫ** — поиск по всем установленным в AE эффектам, эффекты на все слои, свои пресеты, экспорт/импорт.

Внизу вкладок всегда видны **«Создать субтитры»** и подсказка.

**Быстрая регулировка сдвига:** кнопки **−0.5 / −0.1 / +0.1 / +0.5** рядом с полем «Сдвиг» (RU во вкладке «Стиль», EN во вкладке «Дорожки») — подстройка рассинхрона с аудио одним кликом, без набора цифр.

## Единые фишки стиля текста (v1.8+)

Секция **«Стиль текста»** — поведение текстовых слоёв (плашки в стиле Premiere Pro 24 удалены из v1.8.0):

- **Поле «Шрифт» — это живой поиск (v1.19.10)** — печатаешь часть названия, и под полем выпадает список **установленных в AE шрифтов** (`app.fonts.allFonts`, работает с AE 24.0): по одному пункту на семейство (из группы берётся начертание «Regular»), имена как в Character-панели, без дублей. До 24 совпадений — сначала те, что **начинаются с запроса**, потом те, что «содержат». Клик по совпадению записывает полное имя в поле; счётчик рядом — «шр.:N» (всего установлено) или «найдено: N». Кнопка **«↻»** перечитывает список после установки новых шрифтов. Поле остаётся обычным текстовым полем — пресеты, снапшоты и экспорт работают как раньше; ошибки в имени не страшны (падение на Arial), а пустое поле при старте всегда покажет установленные.
- **Убирать зн. препинания** — точки/запятые/?/!/кавычки вычищаются из текста RU и EN дорожек (чистый CapCut-вид).
- **Под размер компа** — шрифт, отступы, обводка и плашечные отступы масштабируются под высоту композиции (референс 1080p); перенос строк считается по ширине компа, длинные слова рвутся — строки не выходят за край.
- **Анимация** — одинаковая для всех слоёв: Затухание / Pop (масштаб) / Слайд вверх / Без анимации. Только ключевые кадры, без выражений.
- **Субтитры по одному слову** — караоке-режим: реплика делится на слова, каждое живёт свою часть времени.
- **Мин. показ, с** — полировка тайминга: минимум времени на экране, реплики не наезжают друг на друга, сетка по целым кадрам.
- **Умный тайминг (v1.21)** — галочка: длительность каждой реплики прикидывается по числу слов (~0,35 с на слово, потолок 6 с, минимум — «Мин. показ, с»). Короткое «Да.» не висит полторы секунды, длинная фраза дотягивается, чтобы успеть прочитать. Растягивается только в свободное место — до старта следующей реплики, наезжать нельзя. Работает для обеих дорожек, состояние входит в пресеты и автозапоминание. Выкл. — тайминг ровно как сказал Whisper.
- **Диапазон показа (v1.25)** — поля «Показ: с … до … сек» во вкладке «Стиль» (пусто = весь ролик, как раньше): субтитры создаются только для отрезка — например, с 5 секунд до 2 минут. Реплики вне диапазона пропускаются, задевшие границы — обрезаются по ним; полировка и умный тайминг не выталкивают реплику за правую границу. Формат гибкий: `5`, `90.5`, `1:30`. Перепутали «с» и «до» — меняются местами сами. Поля не запоминаются после перезапуска AE — чтобы диапазон не остался включённым случайно. Работает для обеих дорожек.
- **«Снять стиль» (v1.22)** — кнопка у поля шрифта во вкладке «Стиль»: выбери в таймлайне ЛЮБОЙ текстовый слой (например, скопированный из чужого ролика) — панель прочитает его шрифт, размер, цвет, обводку и отступ снизу и заполнит свои поля. Дальше «Создать субтитры».

- **Караоке (v1.18+)** — настоящая подсветка слов по таймингам Whisper (`--word_timestamps`): реплика = базовый слой + жёлтый дубль «♪», Source Text шагает hold-ключами по словам. Галочка во вкладке «Стиль», вкл. по умолчанию; работает с новой расшифровкой (kar.json рядом с SRT).
- **Фон-полоса (v1.19+)** — тёмная скруглённая полоса ЗА текстом каждой реплики (shape-слой-ребёнок, без выражений): читаемость на светлом/пёстром видео, стиль CapCut. Опционально, по умолчанию выкл.; входит в свои пресеты.
- **Массовая замена (v1.17+)** — в редакторе субтитров: «Найти» → «Заменить на» → «Заменить все» — правка всех реплик разом (регистр не важен), потом «Сохранить SRT».
- **Реплика ↔ CTI (v1.17+)** — выбор реплики в редакторе двигает Current Time Indicator активного компа на её старт; двойной клик выделяет все слои реплики в компе (v1.19.2).
- **Пауза, кадр.: 2** — пауза между репликами в кадрах; `0` = без добавленной паузы.
- **Вплотную: субтитры идут без пауз** — галочка для сплошного потока: каждая реплика начинается ровно там, где кончилась предыдущая (+ зазор из «Пауза, кадр.», 0 = стык в стык). Естественные паузы Whisper (тишина между фразами) убираются; первая реплика остаётся на своём месте. Без галочки — естественный тайминг Whisper с полировкой (мин. показ, защита от наезда).

Свой пресет («💾 Сохранить») тоже считается «своим стилем» и гасит подсветку встроенного. Состояние переживает перезапуск AE.

Имена свойств — как в Effect Controls (Radius, Exposure, Threshold, Distance, Size, Opacity, Glow Intensity...). Пусто или без скобок — настройки плагина по умолчанию. **v1.19.9:** поддержаны двумерные (`Position=10, 20` или `[10,20]`) и цветовые (`Color=255,40,0` — RGB 0–255, переводится в 0–1) свойства; список эффектов режется с учётом скобок — запятые внутри `(...)` больше не рвут запись эффекта.

В открывшемся окне правишь только нужное («↺» возвращает значение по умолчанию) → «⤴ В список» **сама собирает** строку `Имя(Свойство=…; …)` и заменяет прежнюю запись этого же эффекта в списке «На все слои» (ничего не тронуто → добавится просто имя, параметры по умолчанию). Пробный комп удаляется сразу — Ctrl+Z откатывает весь замер одним шагом.
- **«Параметры:»** — строка редактора на каждый эффект списка (правишь на месте, список обновляется сам, «✕» убирает эффект из списка).

- **«💾 Сохранить»** — свой пресет: имя + все настройки вкладки «Стиль» + эффекты с параметрами + тайминг. Переживает перезапуск AE. Экспорт/импорт пресетов в файл `.txt` — можно передавать другу.

## Модели Whisper (v1.10+)

В выпадашке «Модель»: **tiny / base / small / medium / large / turbo**.

- **small** (по умолчанию) — оптимум для роликов Hunt.
- **large** — максимум качества распознавания; при первом запуске качается ~3 ГБ и на 1.4-мин ролике занимает ~1 мин на RTX 4060 Ti.
- **turbo** — почти качество large, но в разы быстрее (большой плюс для длинных записей).

## Редактор субтитров (v1.9+)

Whisper иногда пишет ошибками — панель умеет их править, не выходя из AE:

- Кнопка **«✎ Редактор субтитров — исправить распознанное»** (секция «Дорожки») открывает отдельное окно.
- Сверху — дорожка (Файл 1 RU / Файл 2 EN) и список **всех реплик** с тайм-кодами.
- Выбираешь реплику → **CTI прыгает на её старт** (v1.17+), правишь текст в поле ниже → переходишь к следующей (правка применяется автоматически).
- **Двойной клик по реплике** (v1.17+, доведено в v1.19.2) — выделяет в активном компе **все слои реплики**: базовый + «♪»-дубль + фон-полосу (в режиме «по одному слову» — все слова реплики). Слои находятся по метке реплики в комментарии, поэтому нумерация имён больше не важна. Для субтитров, созданных старыми версиями, работает прежний поиск по имени — чтобы метки появились, пересоздай слои.
- **«Сохранить SRT»** переписывает файл (тайм-коды не трогаются, кодировка UTF-8).
- **Найти (v1.15+)** — поле поиска по тексту реплик с обходом списка по кругу («Искать далее»).
- **Заменить все (v1.17+)** — «Найти» → «→ Заменить на» → «Заменить все»: массовая правка всех реплик разом (регистр не важен; например, одно имя Whisper писал неправильно — заменяется во всём файле).
- **«(!) быстрые» (v1.22)** — галочка в редакторе (ВЫКЛ по умолчанию): реплики быстрее 20 символов в секунду помечаются маркером «(!)» в номере — правь их тайминги прицельно.
- **Разделить / Склеить (v1.22)** — кнопки в редакторе: «Разделить реплику» режет её по слову, ближайшему к середине (время — пропорционально длине частей), «Склеить с предыдущей» объединяет с предыдущей (текст через пробел, время суммируется). После — «Сохранить SRT».
- Дальше обычное **«Создать субтитры»** — слои строятся уже по правленному тексту.
- Если файл ещё не выбран, редактор сам подхватывает SRT рядом с видео (как «Загрузить SRT»).

## Решение проблем

- **Кракозябры вместо русских букв** — переключите кодировку на `windows-1251` (файл был сохранён из Windows в ANSI).
- **Панель не появляется в меню Window** — см. "Если AE крякнутая", пункт 2.
- **AE ругается при импорте** — включите галочки в Preferences > Scripting & Expressions.
- **Тормозит при 1000+ субтитров** — во-первых, ставьте затухание = 0 (меньше keyframes), во-вторых, импортируйте часть файла (SRT можно резать на куски).
- **Переводчик выдаёт ошибки** — увеличьте `-DelayMs` (например, 500–800) и повторите.
- **Удаление плагина** — просто удалите `AutoSubtitles.jsx` из папки `ScriptUI Panels`.

## Что где лежит

```
AutoSubtitles-AE\
├── AutoSubtitles.jsx             ← сама панель (главное)
├── transcribe-video.ps1          ← обёртка Whisper (консоль)
├── translate-srt.ps1             ← переводчик SRT (консоль)
├── УСТАНОВКА.txt                 ← инструкция для другого компьютера
├── собрать-архив-для-друга.ps1   ← пакует всё в один zip для отправки другу
├── sample.ru.srt                 ← пример русской дорожки
├── sample.en.srt                 ← пример английской дорожки
└── README.md
```

Поделиться панелью с другом: запусти `собрать-архив-для-друга.ps1` (правый клик → «Выполнить с помощью PowerShell») — рядом появится `AutoSubtitles-AE-v<версия>.zip` со всеми файлами; друг распаковывает и ставит по `УСТАНОВКА.txt`.
