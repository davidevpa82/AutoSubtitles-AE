AUTO SUBTITLES — установка на другом компьютере
=================================================

ЧТО НУЖНО
1) Adobe After Effects 2020-2024 (проверено на 2024, v24.x)
2) Python 3.11 / 3.12 / 3.13 (64-bit)
3) ffmpeg

ШАГ 1. ФАЙЛЫ ПАНЕЛИ
Скопируй ТРИ файла в папку панелей AE:
   AutoSubtitles.jsx
   transcribe-video.ps1
   translate-srt.ps1
в папку:
   %APPDATA%\Adobe\After Effects\<номер>\Scripts\ScriptUI Panels\
(номер папки = версия AE: 2024 → 24.x, например 24.6.
 Смотри, какие папки уже есть в %APPDATA%\Adobe\After Effects\)

ШАГ 2. НАСТРОЙКА AE
Edit > Preferences > Scripting & Expressions >
   ВКЛ "Allow Scripts to Write Files and Access Network"
Перезапусти AE. Панель появится в меню Window → Auto Subtitles (внизу списка).

ШАГ 3. WHISPER + FFMPEG (один раз, в PowerShell):
   winget install --id Gyan.FFmpeg -e
   pip install openai-whisper
(если python не в PATH: py -3 -m pip install openai-whisper)
Модели Whisper скачаются АВТОМАТИЧЕСКИ при первом запуске
(tiny ~75 МБ, base ~140 МБ, small ~461 МБ).

ШАГ 4. (ОПЦИЯ) УСКОРЕНИЕ НА RTX
Если есть NVIDIA-видеокарта со свежим драйвером:
   pip install torch --index-url https://download.pytorch.org/whl/cu130
Заменит CPU-torch на GPU — расшифровка в 5-25 раз быстрее
(1.4-мин ролик: ~16 сек с small вместо ~6 мин на CPU).

КАК ПОЛЬЗОВАТЬСЯ
1. Выбери видео → «Whisper → SRT»: расшифровка речи.
   Консоль называется AUTO SUBTITLES - WHISPER, проценты и
   «осталось ≈ N мин · к ЧЧ:ММ» — прямо в панели AE.
   На строке прогресса — устройство и сегменты:
   «whisper small · CUDA · 51/124 сегм.» (двигается каждый тик).
   «Стоп» рядом останавливает Whisper.
2. «Загрузить SRT» → «Создать субтитры» (RU снизу, EN поверх — опция).
   КАРАОКЕ (подсветка слов по ходу речи, как в TikTok): включено по
   умолчанию галочкой «Караоке: подсветка слов по речи» (вкладка «Стиль»).
   Просто запусти «Whisper → SRT» — рядом с субтитрами появится файл
   <имя>.ru.kar.json, а «Создать субтитры» нарисует подсветку:
   каждое реплика — два слоя (текст + жёлтый «♪», который красит
   сказанную часть текста слово за словом). Перезапуск Whisper
   нужен только для уже расшифрованных роликов — со старыми SRT
   (без kar-файла) субтитры создадутся обычными.
3. СЛОВАРЬ (твой жаргон и имена): поле «Словарь:» на вкладке «Видео».
   Напиши через запятую — Whisper будет писать их правильно
   («Карпушов, TikTok, майнкрафт»). Хватает 5-15 слов.
Или одним путём:
   Выбери слой mp4 в таймлайне → «Субтитры ОТ ВЫБРАННОГО СЛОЯ».
   Если SRT ещё нет — первый запуск сам запустит Whisper по видео слоя;
   после «ГОТОВО» нажми кнопку ещё раз — субтитры встанут.

ПОДСКАЗКИ
• Если Windows SmartScreen ругнётся на чёрное окно консоли —
  «Подробнее» → «Выполнить в любом случае» (это твой Whisper).
• AE во время расшифровки НЕ виснет: Whisper живёт в отдельном окне.
• Полировка тайминга уже включена: реплики не наезжают друг на друга,
  минимальный показ настраивается («Мин. показ, с»).
• УМНЫЙ ТАЙМИНГ (галочка во вкладке «Стиль»): длительность реплики —
  по числу слов (~0,35 с на слово, потолок 6 с). Короткое «Да.»
  не висит, длинная фраза дотягивается, чтобы успеть прочитать.
  Растягивается только в свободное место, наезжать нельзя.
• СУБТИТРЫ НЕ НА ВЕСЬ РОЛИК: поля «Показ: с … до … сек» во вкладке
  «Стиль» — например 5 и 1:30. Реплики вне диапазона пропускаются,
  задевшие границы — обрезаются. Пусто = весь ролик. Формат: 5,
  90.5 или 1:30. Не запоминается — после перезапуска AE пусто.
• Плашки в стиле Premiere Pro 24 удалены из панели (v1.8) —
  создаются только текстовые слои.
• Пауза между репликами: поле «Пауза, кадр.:» (по умолчанию 2,
  0 = без добавленной паузы). Чтобы реплики шли одна за другой ровно,
  стык в стык (без зазоров Whisper), включи галочку
  «Вплотную: субтитры идут без пауз».
• Ошибки распознавания правятся прямо в панели: кнопка
  «✎ Редактор субтитров» — отдельное окно, список реплик,
  правка текста, «Сохранить SRT», затем «Создать субтитры».
• Массовые правки в редакторе: «Найти» → «→ Заменить на» →
  «Заменить все» — правит все реплики разом (регистр не важен,
  например Whisper всё время пишет «Шоша» вместо «Саша»).
• Разрезать/склеить реплику: в редакторе кнопки «Разделить
  реплику» (по слову у середины, время пропорционально) и
  «Склеить с предыдущей». Галочка «(!) быстрые» помечает реплики,
  которые читаются быстрее 20 симв/с.
• Пакетная расшифровка: кнопка «Пакет: папка видео» — все ролики
  папки расшифруются по очереди (статус «[номер/всего]» в панели).
• Глоссарий перевода: рядом с видео файл <видео>.glossary.txt,
  строки «термин=замена» — имена и термины не переводятся
  (галочка во вкладке «Видео»).
• «Снять стиль» (вкладка «Стиль»): выбери чужой текстовый слой —
  панель скопирует его шрифт/размер/цвет/обводку в свои поля.
• «Проверка: всё готово?» (вкладка «Видео») — чек-лист: видео,
  SRT, модель, ffmpeg — удобно на новом компьютере.
• Реплика ↔ таймлайн: клик по реплике в редакторе двигает
  индикатор времени (CTI) активного компа на её старт;
  двойной клик — выделяет в компе ВСЕ слои реплики (база +
  караоке-«♪» + фон-полоса, а в «по одному слову» — все слова):
  правь стиль сразу всему, не листая сотни слоёв.
• Стиль разом: кнопки-пресеты «CapCut / TikTok / YouTube / Минимал»
  в секции «Стиль» — заполняют все настройки стиля одним кликом.
  Пресет — ПЕРЕКЛЮЧАТЕЛЬ: активный подсвечен синим, повторный клик
  снимает его («свой стиль», значения остаются). Ручная правка любого
  поля стиля снимает подсветку сама.
• Читаемость на светлом видео: галочка «Фон: тёмная полоса за текстом»
  (вкладка «Стиль», ВЫКЛ по умолчанию) — скруглённая полоса ЗА текстом каждой
  реплики. Для RU/EN, караоке и «по одному слову» (там полоса одна на
  всю реплику, по ширине самого длинного слова). Входит в свои пресеты.
• Кайф для друзей на других программах: в «✎ Редактор субтитров» кнопка
  «ASS (караоке)» (v1.19.5) пишет .ass файл РЯДОМ с SRT — та же
  подсветка слов по таймингам Whisper (нужен kar.json рядом с SRT),
  стиль из панели (жёлтый акцент, подложка/обводка). Открывается в VLC,
  DaVinci, Media Player Classic, Premiere (плагины); проект AE не меняет.
• ПРИКРЕПИТЬ панель справа (как остальные панели): закрой
  плавающее окно, открой панель через меню «Окно (Window)» —
  пункт Auto Subtitles.jsx внизу списка — и потяни её ярлык
  к правому краю AE до подсветки, отпусти. Можно добавить
  вкладкой в группу с другими панелями.
• Панель разбита на 4 вкладки (Видео, Дорожки, Стиль, Эффекты) —
  кнопки-вкладки вверху, как в макете; кнопка
  «Создать субтитры» всегда на виду сверху.
• Чистка запинок Whisper: галочка «Чистить запинки (повторы
  слов)» (вкл по умолчанию) удаляет «и и», «да да» и прочие
  повторы подряд из обеих дорожек до создания слоёв.
• Пересоздание без дублей: галочка «Стереть прежние субтитры
  (RU/EN)» во вкладке «Дорожки» удаляет старые слои панели перед
  созданием новых.
• Скачивание моделей: в несколько потоков и с ДОКАЧКОЙ.
  Выбор — строка «Скачивание: N потоков» на вкладке «Видео» (4-8
  обычно быстрее всего). Если интернет оборвался — запусти
  «Whisper → SRT» ещё раз: модель продолжится с места обрыва,
  ничего не перескачается заново.
• Рассинхрон с аудио правится кнопками «−0.5 / −0.1 / +0.1 / +0.5»
  у поля «Сдвиг» (RU — во вкладке «Стиль», EN — во вкладке «Дорожки»).
• Модель точнее: «Модель: large» (первый запуск качает ~3 ГБ)
  или «turbo» — почти как large, но быстрее.
• Свои эффекты и их ПАРАМЕТРЫ: в списке «На все слои» —
  формат «Имя(Свойство=значение; ...)» — например
  «Deep Glow(Radius=25;Exposure=1.2)». Значения подставляются
  на каждый создаваемый слой. Строки параметров правятся
  в панели (вкладка «Эффекты»), есть кнопки готовых вариантов.
  Двумерные и цветовые свойства тоже можно: «Position=10, 20»,
  «Color=255,40,0» (RGB 0–255). Запятые внутри скобок не ломают список.
• ПОИСК эффектов: поле «Поиск:» (вкладка «Эффекты») ищет ТОЛЬКО среди
  эффектов, РЕАЛЬНО установленных на этом компьютере — родные AE и
  любые плагины. Печатай часть названия («glow», «drop») — список
  покажет совпадения, «+» добавляет в список. Пусто — установленные
  (популярные из них сверху), счётчик «ус.:N» показывает, сколько
  всего эффектов есть в AE. Не установленныйByName в списке НЕ появится.
• ПОИСК шрифтов: поле «Шрифт» во вкладке «Стиль» — это одновременно
  значение И поиск. Печатай часть названия («mont») — под полем
  выпадает список шрифтов, РЕАЛЬНО установленных в AE (с AE 24.0).
  До 24 совпадений: сначала те, что начинаются с запроса, потом те,
  что содержат. Клик по совпадению — полное имя встанет в поле.
  Счётчик рядом: «шр.:N» — сколько семейств установлено всего,
  «найдено: N» — сколько совпало. Кнопка «↻» перечитывает список после
  установки новых шрифтов. Если список шрифтов недоступен (старая AE),
  панель покажет популярные шрифты с той же фильтрацией.
• Свои пресеты: кнопка «💾 Сохранить» — сохраняет стиль +
  эффекты с параметрами + тайминг под своим именем (переживает
  перезапуск AE). Обмен с друзьями: «⬆ Экспорт» / «⬇ Импорт».
• Настройки панели сами запоминаются: после перезапуска AE
  всё как оставил (стиль, эффекты, тайминг).
• Точность подсчёта субтитров: статистика в окне «Готово!»
  (слова/символы/средний показ и замечание, если читать слишком сложно).

Файлы — свободно распространяются с этой панелью.
Whisper — open source (OpenAI), ffmpeg — open source.
